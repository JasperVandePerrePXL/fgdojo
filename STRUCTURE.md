# Project Structure

This project is now organized into logical folders:

```
fgdojoLeaderboard/
├── scripts/                       # All executable scripts
│   ├── fetch_tournaments.js       # Fetch data from start.gg
│   ├── process_leaderboard.js     # Process into leaderboard format
│   ├── process_all_seasons.js     # Process all seasons at once
│   ├── build.js                   # Build for deployment
│   └── server.js                  # Development server
│
├── seasons/                       # Season configuration files
│   ├── season-0.txt               # Tournament slugs for season 0
│   └── season-1.txt               # Tournament slugs for season 1
│
├── data/                          # Generated data files
│   ├── output-season-0.json       # Raw tournament data
│   ├── output-season-1.json
│   ├── leaderboard-season-0.json  # Processed leaderboard
│   └── leaderboard-season-1.json
│
├── public/                        # Static web files
│   ├── index.html                 # Main website
│   └── fgdlogo.jpg                # Logo image
│
├── dist/                          # Build output (for deployment)
│   ├── index.html
│   ├── fgdlogo.jpg
│   └── leaderboard-season-*.json
│
├── .env                           # Environment variables (API key)
├── package.json                   # Project configuration
└── README.md                      # Documentation
```

## Folder Purposes

### `/scripts`
All Node.js scripts that perform operations:
- Data fetching
- Data processing
- Building
- Development server

### `/seasons`
Text files containing tournament slugs for each season.
- One file per season: `season-X.txt`
- One slug per line
- Comments allowed with `#` prefix

### `/data`
Generated JSON files from processing:
- Raw tournament data: `output-season-X.json`
- Processed leaderboards: `leaderboard-season-X.json`
- **Not committed to git** (in .gitignore)

### `/public`
Static files served to users:
- HTML pages
- Images
- CSS/JS (if added later)

### `/dist`
Build output ready for deployment to S3 or other hosting.
- Contains only files needed for production
- Generated by `npm run build`

## Usage

### Development
```bash
npm start                    # Starts dev server at http://localhost:3000
```

### Process Seasons
```bash
npm run refresh              # Process all seasons
node scripts/fetch_tournaments.js 0    # Fetch season 0
node scripts/process_leaderboard.js 0  # Process season 0
```

### Build for Deployment
```bash
npm run build               # Creates dist/ folder with all files
```

## Season Dropdown

The season dropdown **automatically detects available seasons** by:

1. **Development mode** (when running `npm start`):
   - Calls `/api/seasons` endpoint
   - Server reads `seasons/` folder
   - Returns list of all `season-X.txt` files

2. **Production mode** (when deployed):
   - Checks for `data/leaderboard-season-X.json` files
   - Tries HEAD requests for seasons 0-9
   - Returns list of existing files

**No manual configuration needed!** Just add a new `season-X.txt` file, process it, and it will appear in the dropdown.

## Files That Can Be Deleted

The following files are no longer needed:
- `refresh.js` (replaced by `process_all_seasons.js`)
- `leaderboard.json` (old format, now using `leaderboard-season-X.json`)
- `output.json` (old format, now using `output-season-X.json`)

Run this to clean up:
```bash
# Remove old files
Remove-Item -Force refresh.js, leaderboard.json, output.json 2>$null
```
